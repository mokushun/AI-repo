# m1-research（m1.db を使った検証の共同作業スペース）

作成: 2026-10-27（Muse）

## 目的

OANDA 1分足データベース `m1.db` を唯一の検証材料として、投資戦略・分析レポートの主張を
「文章」ではなく「再実行できるコードと出力」で検証する。複数AIの共同開発スペースとする。

## このスペースのルール（リポジトリ全体のルールとの違い）

- **ここは編集自由**。他のプロジェクト（spx-judgment 等）の読み取り専用ルールはここには適用しない
- ただしリポジトリ全体の基本ルール（秘密情報を書かない、無料枠、売買・注文はしない＝記録・検証・シミュレーションのみ）は従う
- **数字を文書に書くときは、生成したスクリプトとその出力を必ずこのフォルダに残す**。
  スクリプトのない数字は「未検証」と明記する（2026-10-27 の教訓：コードのない分析レポートは検証不能だった）
- 定義（価格は bid/ask/mid のどれか、スプレッドの扱い、TP/SL の優先順位、タイムゾーン）を
  スクリプト冒頭か文書に明記する。JST か UTC かは必ず書く
- 結果が悪くても消さない。反証された仮説は findings/ に「反証済み」として残す

## データ（リポジトリには入れない）

| データ | 置き場所（Muse VM） | 内容 |
|---|---|---|
| `m1.db` | `~/workspace/oanda_json/m1.db`（環境変数 `M1_DB_PATH` で変更可） | SQLite、約1.27GB。テーブル `m1`（inst, t=epoch秒, bid/ask OHLC）。6銘柄（JP225_USD, NAS100_USD, SPX500_USD, USD_JPY, WTICO_USD, XAU_USD）、2020-10-01〜2026-10-22 UTC、12,740,048行 |
| `n225mini_options_master.csv` | `~/workspace/oanda_json/`（環境変数 `N225_CSV_PATH`） | 日経225ミニオプション（金曜限月）の時間毎スナップショット。手元の写しは 2026-09-02〜10-05 分まで（776回）。VPS側マスターとは別物かもしれない点に注意 |

## 構成

- `scripts/` : 検証スクリプト。実行すると標準出力に結果を出す
- `outputs/` : スクリプトの実行出力（証拠として保存。日時と条件が分かる名前・内容にする）
- `findings/` : 検証結果のまとめ（日付_テーマ.md）。結論・根拠・不確かな点を分けて書く
- `BACKLOG.md` : 次に検証したいこと

## 実行方法（例）

bash で、リポジトリのこのフォルダに移動して実行する。

python3 scripts/verify_nikkei.py
python3 scripts/analyze_skew.py

`analyze_skew.py` は入力CSVと同じフォルダに `skew_series_bot.csv` を生成し、`run_skewbot_repro.py` はそれを使う（なければ `outputs/skew_series_bot.csv` を参照する）。skew 系を回すときはこの順で実行すること。

前提: python3 + pandas + numpy。データパスが違う環境では `M1_DB_PATH` / `N225_CSV_PATH` を指定する。
