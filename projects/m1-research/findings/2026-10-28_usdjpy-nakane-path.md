# 2026-10-28 仲値トレード：平均的な値動きの経路（IN/OUT 最適化ステップ1）

## 結論

- 夜間の平均経路は「じわじわ上がって 04:15〜05:45 に +2.6 pip 前後のプラトー、
  東京時間の朝に 0 付近まで戻り、仲値直前に再び上がって 09:54 に +1.6 pip、
  10:00 には +0.9 pip へ後退」という形。単一の尖った時刻ではなく
  04:15〜05:45 の広いプラトーがピークなので、OUT を数十分ずらしても
  平均はあまり変わらない。
- **木曜の早期決済は、価格だけ見ても「コスト」ではなく「得」だった。**
  通常時刻まで持つと、A で −7.35 pip（t=−5.27、ペア n=310）、
  B で −7.29 pip（t=−4.43、ペア n=312）悪化する。スワップ回避分は
  その上乗せになる。木曜の朝 05:00→09:00 帯が木曜以外より弱い。
- ゴトー日は夜通し高い（A 05:45：ゴトー日 +4.37 vs それ以外 +2.24、
  09:54：+4.92 vs +0.79）。仲値直前だけの話ではない。
- 期間別では、2024 年以降の方が早朝プラトーが高い（A 05:00：+3.45 vs
  2023 年以前 +1.05）が、仲値ピークは逆に低い（09:54：+1.21 vs +1.92）。
  IN/OUT のグリッド最適化では前半・後半で選ばれる時刻がずれる可能性があり、
  プラトー採用の条件が要る。

## 根拠（スクリプトと出力）

- `scripts/usdjpy_nakane_path.py`、`outputs/usdjpy_nakane_path_out.txt`
- 母集団：決済日 火〜金、IN の足があるセッション 1,257 件
  （2020-10-02〜2026-10-22）。前段 `usdjpy_nakane_current.py` と同一母集団。
- 定義：ロングのみ、約定は指定時刻の足の始値（IN は ask、評価は bid）、
  単位 pip（1 pip = 0.01 円）。価格のみで、スワップ・スリッページは含まない。
- 経路の抜粋（A 23:00 IN、ロング、全体平均）：
  23:00 −1.81（スプレッド分）→ 01:00 +0.29 → 03:30 +1.64 →
  04:55 +1.89 → 05:45 +2.65（ピーク）→ 08:00 +0.45 → 08:54 +0.02 →
  09:54 +1.59 → 10:00 +0.87。B 00:00 IN も同時刻ではほぼ同じ値。
- 整合性チェック：A 08:54 の全体平均 +0.02 は、前段の +1.83 と
  「木曜だけ早期決済」だった差で説明できる（木曜 310 件 × 7.35 pip ÷
  全体 ≒ 1.82 pip）。B も同様（+1.59 vs 前段 +3.39、差 ≒ 1.81 pip）。

## 不確かな点・注意

- 方向はユーザー未確認。ロングで描いたのは、前段でロング側だけが
  プラスだったため。ユーザーから方向の確認がまだ返っていない。
- 06:00〜07:15 JST の足は欠損が多い（06:00 は n=465、07:00 は n=878）。
  原因は未調査（フィードの日次ブレイクの可能性）。この時間帯の値は
  ピーク判定から除外した。特に 06:00 のゴトー日 +9.69 は
  残ったセッションだけの平均で、読んではいけない。
- 木曜の早期決済とスワップ額の天秤は、ユーザーのスワップ pip 相当が
  分からないと完結しない。ただし価格だけでも早期決済が有利なため、
  スワップ額が分かれば「有利幅はさらに広がる」方向の比較になる。
- 実行頻度（毎日かゴトー日中心か）もユーザー未回答。ここでは全日で測った。
