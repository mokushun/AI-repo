# 仲値トレード 5ペア初回測定（2026-10-29、Muse）

スクリプト: `scripts/nakane_5pairs_firstpass.py`
出力: `outputs/nakane_5pairs_firstpass_out.txt`
データ: 拡張版 m1.db（21銘柄、46,002,239行、2020-10-01〜2026-10-29 UTC、quick_check ok。
USD/JPY の重複期間は旧版と完全一致を確認済み。旧版は `m1_2026-10-22.db` として保持）

## 定義

- 仲値 現行ライブ構成（単一レッグ）: JST 00:00 のバー始値 ASK で買い建て、
  JST 09:55 のバー始値 BID で決済。木曜のみ 05:35 決済。ロングのみ、価格のみ（スワップなし）
- 決済日は火〜金（JST）。ゴトー日 = JST 日付の日 % 5 == 0
- スプレッド測定: 2026-09-01〜10-22、IN/OUT 時刻のバー始値 ask−bid、中央値

## 結論

- 5ペアとも全期間ではプラス。ただし強さはペアで大きく違う
  - GBP_JPY +3.97pip / PF 1.252 / t=2.70（USD_JPY +3.85 / 1.334 / t=3.39 と同格）
  - EUR_JPY +2.71 / 1.220 / t=2.41、CHF_JPY +2.38 / 1.205 / t=2.28
  - AUD_JPY +0.93 / 1.084 / t=0.94 が最弱。非ゴトー日は平均 0.00pip / PF 1.000 で、
    エッジがゴトー日（+4.76）にしかない
- ゴトー日プレミアムは5ペア共通（+4.76〜+9.82pip）。CHF_JPY のゴトー日が
  PF 2.173 / t=4.31 と最も強い
- 2026年9〜10月は USD_JPY だけ強く（+8.17）、他4ペアは +0.65〜+1.66pip と
  ほぼ横ばいの小幅プラス。実売買で同期間に GBP・CHF が弱かったという体感は、
  価格（OANDA M1、約定可能ベース）だけでは再現しない
  → 実売買のマイナスの主因は価格以外の要因（トレーリングストップ、スワップ、
  約定価格の差、ゴトー日の数量集中）に残る
- OANDA のスプレッドはクロス円で広い（往復コスト中央値: USD 1.60、AUD 2.30、
  EUR 2.75、GBP 3.33、CHF 4.05 pip）。GMOコイン実測（同期間・同方法、チャットで測定、
  スクリプト未保存=参考値）との合計コスト比較では、全ペアで GMO が
  0.47〜2.16pip/トレード安い（API手数料込み）。ただし GMO は提示レートベースで
  約定スリッページ未検証

## 不確かな点

- スワップは含んでいない。特に CHF_JPY ロングは 2026 年の金利環境では
  マイナススワップの可能性があり、実売買損益とは乖離しうる
- トレーリングストップ（実売買コードで毎分動作、意味は oanda_API 側で未確認）の
  影響はこの測定に入っていない
- Sep-Oct 2026 は n=31 と小さく、ゴトー日分割（n=6）はしていない
- ペア追加に伴う最適 IN/OUT の再グリッドは未実施（現行時刻を全ペアに横並びで適用した初回測定）
