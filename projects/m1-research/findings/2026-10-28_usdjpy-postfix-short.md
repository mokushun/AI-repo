# 検証サマリー 2026-10-28（USD/JPY 仲値後のショート：9:56 売り）

検証者: Muse
根拠: `scripts/usdjpy_postfix_short.py` / `outputs/usdjpy_postfix_short_out.txt`

## 問い

仲値到達後の 09:56 で売りを入れる戦略は機能するか。
ユーザーは実際に半年売って「駄目だった」とのこと（曜日×ペア PF 表を共有）。
EA 内蔵の売りレッグ（09:54→11:00）も MT5 2回のレポートで PF 0.912〜0.972 だった。

## 定義（固定仕様）

- データ: m1.db、USD_JPY、2020-10〜2026-10、JST 月〜金（n=1,571）。約定は指定時刻の足の始値
- ショート損益 = bid始値(IN) − ask始値(OUT)、pip 表示。スワップなし
- IN: 09:54（EA版）/ 09:55 / 09:56（ユーザーの実売り）。OUT: 10:00 / 10:30 / 11:00 / 12:00 / 15:00
- mid ベースの gross（コスト前）も併記する

## 結論

**機能しない。ユーザーの実売りの結果と一致する。**
仲値後の下げ自体は実在するが（mid で 09:56→11:00 に +0.90 pip、t=2.05）、
往復スプレッド（約1.6 pip）より小さいため、実価格では −0.74 pip / PF 0.883 に沈む。
スキャルピングのときと同じ「現象はあるがコストの壁以下」の構図。

## 根拠

- 主仕様 09:56 → 11:00: 平均 −0.74 pip、PF 0.883、勝率 48.4%（n=1,571）
- IN を早めても届かない: 09:55 → 11:00 で −0.08 pip / PF 0.987 が最良、
  09:54 → 11:00（EA版）でも −0.46 pip / PF 0.930（MT5 実測 0.912〜0.972 と整合）
- **09:56 IN が一番不利な理由**: 下げのいちばん大きい部分が 09:55→09:56 の1分に入っている
  （gross は IN 09:55 で +1.59 pip、IN 09:56 で +0.90 pip）。仲値が付いてから売ると
  その分を取り逃がし、スプレッドだけ全額払う
- OUT は 10:30〜11:00 が底で、それより先（12:00 / 15:00）は gross 自体が消える
- 曜日別（09:56→11:00）: 月 −0.48 / 火 −0.92 / 水 −1.28 / 木 **+0.37（PF 1.061）** / 金 −1.40。
  木曜だけプラスなのは、木曜は仲値に向けて下げた流れが午前も続くためとみられる
- ゴトー日は +0.90 pip / PF 1.172（n=303、t=0.99 で有意でない）、非ゴトー日は −1.13 pip / PF 0.828。
  仲値需給の巻き戻しはゴトー日に集中するが、それでも有意水準には届かない
- 期間後半ほど悪い: 2020-10〜2023 で PF 0.952、2024〜2026 で PF 0.827（2026 は 0.677）

## ユーザーの実績表との照合

- 全体に PF < 1 が支配的という結論は一致する
- 曜日×USD/JPY の形は一致しない（実績: 月 1.64 / 火 0.67 / 水 0.67 / 木 0.33 / 金 0.35。
  m1.db: 月 0.929 / 火 0.839 / 水 0.795 / 木 1.061 / 金 0.794）。
  実績は半年分で曜日あたり約26日しかなく、セル単位の PF はノイズが大きい。
  また実績の OUT 時刻が 11:00 とは限らないため、セルの食い違いは不思議ではない

## 不確かな点

- 他ペア（AUD/JPY 等）は m1.db に無く未検証。実績表では通貨ペアでかなり形が違う
- 09:55 ちょうどの価格（仲値そのもの）で売れた場合の試算は 09:55 IN に含まれるが、
  それでも PF 0.987 と分岐点に届かない
