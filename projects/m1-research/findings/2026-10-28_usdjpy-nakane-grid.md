# 検証サマリー 2026-10-28（USD/JPY 仲値トレード：IN/OUT 時刻の最適化）

検証者: Muse
根拠: `scripts/usdjpy_nakane_grid.py` / `outputs/usdjpy_nakane_grid_out.txt`
（現行仕様の事前実測は `scripts/usdjpy_nakane_current.py` / `outputs/usdjpy_nakane_current_out.txt`）

## 前提（ユーザー確認済み）

- ロングのみ、毎日実行。同時に AUD/JPY・CHF/JPY・EUR/JPY・GBP_JPY も同型で回しているが、
  m1.db にあるのは USD_JPY だけなので、検証は USD_JPY のみ。他ペアは未検証
- 現行: A 23:00 IN → 08:54 OUT、B 00:00 IN → 09:54 OUT（JST）。木曜のみ A 04:55 / B 05:55 に早期決済
- スワップは価格データに無いため含まない（価格のみ）。木曜の早期決済はユーザーが
  「仲値まで持つより PF が良かった」経験で採用したもの

## 定義（固定仕様）

- 対象は決済日（仲値の日）が火〜金の日（n≈1,250）。月曜決済は夜間INが市場休場で存在せず、
  土曜は仲値がないため除外（土曜を含めると早朝OUTが金曜夜の米国時間の値動きを拾ってしまう）
- 約定は指定時刻の足の始値。ロング損益 = bid始値(OUT) − ask始値(IN)、pip 表示
- グリッド: IN は前日20:00〜02:00 を15分刻み、OUT は 04:00〜10:30 を5分刻み＋08:54/09:54
- 平均経路: mid 始値の前日20:00起点の累積変化。経路の日次構成が変わらないよう、
  起点と09:55の両方のバーがある日に限定
- 過適合対策: 前半（〜2023）/ 後半（2024〜）の相互転移、近傍プラトー、上位は面で見る

## 結論

1. **IN は現行（23:00 / 00:00）でほぼ最適域**。上位は IN 22:45〜00:00 の幅広い面で、
   時刻差の効果は誤差範囲。01:00 IN は明確に悪い
2. **OUT に2つの山と1つの谷がある**（平均経路と一致）:
   - 山1: **05:15〜05:55**（05:35 で IN 23:00 → +2.74 pip、IN 00:00 → +2.76 pip）
   - 山2: **09:55 ちょうど**（09:54 より +0.37 pip。ただし1分の差で額は小さく、実執行で
     仲値の価格で売れるかは別途確認が要る）
   - 谷: **08:54**。経路では 08:30〜09:00 が窪む。現行 A の弱さ（+1.83 pip、PF 1.136）はほぼこれで、
     A の通常日 OUT を 09:55 型に変えたハイブリッドでは +3.84 pip / PF 1.285（現行Aとの paired 差 +2.01 pip、t=3.78）
3. **木曜の早期決済は、スワップを持ち出すまでもなく価格だけで正解**:
   木曜に仲値まで持つと −3.3〜−4.0 pip、早期決済だと +3.2〜+4.0 pip、差は約 +7.2 pip。
   現行ハイブリッドと「毎日仲値まで」の paired 差は A +1.83 pip（t=5.11）/ B +1.82 pip（t=4.33）。
   つまり木曜の朝（05:55→09:54）は系統的に下げる局面で、ユーザーの PF 観測と一致する
4. **候補ルール（価格のみ）**: IN 00:00、OUT 09:55（木曜 05:35）→ +3.85 pip、PF 1.334、t=3.39。
   現行 B（+3.39 pip、PF 1.288）との paired 差は +0.46 pip（t=3.44、ただし差の内訳は
   09:54→09:55 と木曜 05:55→05:35 の2変更の合計）。毎日 05:35 OUT（+2.76 pip、PF 1.284）も
   現行 B とほぼ互角で、現行 B との paired 差 +0.66 pip は有意でない（t=1.12）
5. 曜日別 PF は現行のボリューム配分（火曜最大→金曜最小）と整合: 金曜が最弱
   （A: PF 0.931 / −1.02 pip、B: PF 1.084 / +1.14 pip）、火曜が最強（A 1.331、B 1.458）

## 平均経路の形（火〜金、mid、前日20:00起点）

- 23:00 で −0.6 pip まで沈み、夜間にじわじわ上昇して 05:30 に +3.6 pip
- 07:30〜09:00 に +1.3〜1.9 pip へ窪み、09:55 に +3.1 pip まで戻して、以降は逓減（10:30 で +1.6 pip）
- ゴトー日は全体に大きく（09:30 で +7.6 pip）、非ゴトー日は仲値の山が弱い（09:30 で +0.3 pip）。
  非ゴトー日でも早朝の山（05:30 で +2.7 pip）は残る
- 注意: 06:00〜06:06 の経路の跳ね（+5.08 pip）は日次ブレイク前後のバーの構成変化による
  見かけの可能性が高く、約定ベースのグリッドでは支持されない。採用しない

## 過適合チェック

- 上位15組合せはすべて IN 22:45〜00:00 × OUT 05:15〜05:55 の同一プラトー内で、
  前半・後半ともプラス（H1 +1.6〜+2.4、H2 +3.4〜+4.2）
- 前半ベスト（22:45→05:50）は後半でも +3.38 pip、後半ベスト（23:45→05:20）は前半でも +1.59 pip。
  「片側でだけ光る」組合せではない
- ただし平均 +3 pip に対して日次 std は約40 pip。エッジは「日々のノイズの中の小さな偏り」
  であり、時刻変更で得られる改善幅も paired で見て +0.5〜+2 pip/回が上限と見るべき

## 不確かな点

- スワップは未計入。特に木曜は価格差が +7.2 pip と大きいため、結論はスワップの符号にほぼ依存しないが、
  他曜日の早朝OUT化（05:35）を検討する場合は受け取りスワップとの兼ね合いが残る
- 09:55 OUT の +0.37 pip は、OANDA の 09:55 バー始値での測定。実際のブローカーで
  仲値ちょうどの価格で決済できるかは運用側の確認が要る
- 他のクロス円ペア（AUD/JPY 等）はデータがなく未検証。USD/JPY の時刻最適がそのまま効く保証はない
- A と B は同じ夜の重複ポジションで、2本の損益は強く相関するはず（分散にはならない）
