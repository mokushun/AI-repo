# USD/JPY スキャルピング：残る候補の検証（JST 21〜0時 × 10〜30分、極端変動後の平均回帰）

日付：2026-10-28（JST）。データ：m1.db の USD_JPY（2020-10-01〜2026-10-22 UTC、2,232,589本）。
スクリプト：`scripts/usdjpy_night_holds.py`、出力：`outputs/usdjpy_night_holds_out.txt`。
定義は `usdjpy_basics.py` と同一（実価格での実行可能リターン、重複回避のため間引き t 値を併記）。
しきい値は事前固定：夜間 = JST 21・22・23・0時、保有 10・20・30分、
極端な事前変動 = 直前10分の mid 変動の絶対値 ≥5 pip / ≥10 pip。

## 結論

残る2候補とも、コストの壁を越えない。成行のドル円スキャルピング路線は、
この OANDA フィードの条件では終了としてよい。

- 夜間でも実行可能リターンは −1.5〜−1.7 pip/件（保有 10〜30分、フィルタなし）。
  夜間のスプレッド/レンジ比は 47.4% まで改善する（全体 76.3%）が、
  mid の無条件ドリフトは +0.02〜+0.09 pip と小さく、スプレッド 1.59 pip を埋められない。
- 夜間の EMA エッジは最大でも bull−bear 差 +0.30 pip（20分、間引き t=1.51、有意でない）、
  30分も +0.29 pip（t=0.98）。bull の無条件超過は +0.03〜+0.15 pip。
  点推定をそのまま信じてもスプレッドの約 1/5 で、実行可能リターンは −1.35〜−1.55 pip のまま。
- 極端変動後の平均回帰も、間引き後の回帰方向 mid リターンは概ね 0〜+0.3 pip
  （夜間・≥10 pip・20分だけ +0.58 pip だが t=1.6、有意でなく、実行可能は −1.13 pip）。
  どの条件でも実行可能リターンはマイナスから抜けない。

## 不確かな点・前提の限界

- 結論はこの OANDA フィードのスプレッドと成行（テイカー）執行に限る。
  他業者・ECN の狭いスプレッドや指値（メイカー）執行は M1 では検証できない（基礎測定と同じ留保）。
- 20〜30分の EMA 差 +0.3 pip は点推定では 0.1 pip 桁だが、有意でなく、
  損益分岐に必要な約 1.6 pip には遠い。「0.1 pip 桁のエッジも出なければ終了」という
  2026-10-27 の判断基準に照らしても、実行可能ベースでは終了の結論は変わらない。
- 試した条件は夜間・EMA・極端変動後の回帰のみ。「あらゆる短期シグナルが効かない」ことの証明ではない。
